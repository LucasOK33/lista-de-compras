• Lista de Compras
• Sobre o projeto

Este projeto consiste em uma Lista de Compras, desenvolvida com o objetivo de facilitar a organização dos produtos que precisam ser comprados.

A aplicação permite registrar os itens da lista de forma simples e organizada, ajudando o usuário a controlar suas compras e evitar esquecimentos.

• Objetivo

O objetivo do projeto é criar uma ferramenta simples para organizar uma lista de compras, permitindo visualizar os produtos que precisam ser adquiridos.

Além disso, o projeto foi desenvolvido como uma atividade prática para aplicar conhecimentos básicos de Git e GitHub, trabalhando de forma colaborativa entre os integrantes da equipe.

• Funcionalidades
• Adicionar produtos à lista;
• Visualizar os produtos cadastrados;
• Marcar produtos como comprados;
• Remover produtos da lista;
• Manter a lista organizada.
